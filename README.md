# CareFlow

CareFlow is a standalone hospital command center website designed by me, Simone Govender.

- Front end: custom responsive HTML, CSS, and JavaScript.
- Pages: overview, command center, patients, analytics, database, login, and case study.
- Data: 100 preloaded triage records in `api/data.json`.
- Demo login: `simone@careflow.demo` / `demo123`.
- Static backend for GitHub Pages: `api/data.json` and `api/users.json`.
- Local backend: run `npm start` to use `server/server.js` with `/api/health`, `/api/login`, and `/api/records`.
- Interactions: live command clock, theme toggle, triage simulator, patient lanes, searchable queue, local CRUD database, JSON export, and saved escalation records.
